How to choose your size
  1. Set the Length and Width — type an exact size (50–2400 mm), or use −/+ to add or remove one grating section (50 mm) at a time.
  2. Set the bar height (30 mm or 40 mm) — taller bars carry heavier loads and longer spans.
  3. Pick a cutting type (I–VI) to match your channel: a closed / flush edge gives a finished border, an open / tooth edge lets bars run out so panels butt together or drop over a frame. The preview redraws so you can see the exact edge.
  4. Note your Overall size and Edge finish from the summary, then send them with your enquiry.
